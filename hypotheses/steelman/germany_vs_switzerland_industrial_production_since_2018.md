# Steelman: germany_vs_switzerland_industrial_production_since_2018

Claim: Swiss industry thrives while German industrial production implodes: since 2018 Swiss manufacturing output has grown while Germany's has fallen sharply.

Strongest opposing case: Swiss manufacturing output is dominated by pharmaceuticals, which have boomed globally; German output is concentrated in energy-intensive chemicals and autos hit by the 2022 gas shock and Chinese EV competition. The post's explanation (work ethic, hours) is not tested here.

This test is descriptive, not causal.

Falsification (frozen): Change = mean of latest 4 common quarters vs 2018 mean. SUPPORTED if DEU change <= -8% AND CHE change >= +5%. REFUTED if DEU change >= CHE change. PARTIAL otherwise. Fallback if CHE missing from Eurostat: oecd production index (same rule, disclosed).
