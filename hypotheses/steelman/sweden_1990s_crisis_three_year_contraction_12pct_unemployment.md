# Steelman: sweden_1990s_crisis_three_year_contraction_12pct_unemployment

Claim: Sweden's early-1990s crisis: GDP contracted three years in a row and unemployment reached ~12%.

Strongest opposing case: the test is descriptive, not causal; confounders (cycle, energy-price shocks, compositional change, data revisions, preliminary prints) could produce the same pattern. Falsification: SUPPORTED if NGDP_RPCH < 0 in each of 1991,1992,1993 AND peak LUR 1990-1998 >= 11.0; PARTIAL if exactly one holds; REFUTED if neither.
