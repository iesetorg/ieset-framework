# Steelman: resident patents and high-tech exports

Resident patent applications can proxy domestic inventive activity that might precede export expansion. This country-disjoint test uses log(1+applications) at t and the exact next-year log growth of high-technology export value.

Applications differ in quality and may follow, rather than cause, export success. Both named files mirror distinct World Bank API indicators, and current-USD exports respond to prices and exchange rates. No innovation or industrial-policy mechanism is identified.

The old 30-country SUPPORTED result is disclosed and its entire roster is excluded. The same fixed four-test correction, minimum sample, symmetric opposite-sign rule, and exact source hashes apply. Insufficient complete cases return INCONCLUSIVE. No school claim receives credit.
