# Steelman: us_manufacturing_jobs_change_since_jan_2025

Claim: US manufacturing employment has fallen since January 2025 despite tariffs (vs White House claim of manufacturing job gains).

Strongest opposing case: the test is descriptive, not causal; confounders (cycle, energy-price shocks, compositional change, data revisions, preliminary prints) could produce the same pattern. Falsification: SUPPORTED (jobs down) if CES manufacturing latest - Jan-2025 <= -20k; REFUTED if >= +20k; PARTIAL (flat) otherwise.
