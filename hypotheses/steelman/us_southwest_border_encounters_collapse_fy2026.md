# Steelman: us_southwest_border_encounters_collapse_fy2026

Claim: Southwest-border encounters in FY2026 are down more than 90% versus FY2023 over the same fiscal-year months.

Strongest opposing case: the test is descriptive, not causal; confounders (cycle, energy-price shocks, compositional change, data revisions, preliminary prints) could produce the same pattern. Falsification: SUPPORTED if FY26 YTD / FY23 same months <= 0.10; REFUTED if >= 0.50; PARTIAL otherwise.
