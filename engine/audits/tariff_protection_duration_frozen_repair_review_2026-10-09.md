# Tariff protection duration: frozen repair review — 2026-10-09

**Disposition: no same-ID graduation.** This is a read-only method and source-custody review. No estimate, verdict, registration, or public tier was changed.

The [registered specification](../../hypotheses/trade/tariff_protection_duration_growth_drag.yaml) predates the first run (spec commit `bce8430`, run commit `e786a95`); its current text has no diff from the registered commit. Its primary coefficient is **constructed cumulative years with applied weighted-mean tariffs above 15%**, expressed in decades, with current tariff level controlled. The rule needs a negative, significant duration coefficient for **both** real export growth and real household consumption per capita growth. `PARTIAL` requires a negative, significant export coefficient without the consumption result. The separate `falsification.threshold` also requires the frontier coefficient to be no greater than the catch-up coefficient, while the prose rule calls that comparison informative. The decision role of this comparison is therefore unresolved in the frozen text.

The [old result card](../runs/tariff_protection_duration_growth_drag/result_card.md) and [diagnostics](../runs/tariff_protection_duration_growth_drag/diagnostics.json) instead report one generic panel regression with the **current tariff level** as treatment (`-0.006557`, `p=0.717`). The constructed duration, export complexity, terms-of-trade control, and a run-local replication script/manifest were absent. The generic `PARTIAL` label does not meet the registered `PARTIAL` condition and is not a result for the registered duration test. Adding a replication wrapper around these two old files would replay the wrong estimand.

The source series now present do not resolve the frozen design without new choices:

| Registered requirement | Current evidence boundary |
| --- | --- |
| Real household consumption per capita growth | The spec points to WDI `NE.CON.PRVT.ZS`, which the [World Bank defines as final consumption **% of GDP**](https://data.worldbank.org/indicator/NE.CON.PRVT.ZS). The correct real per-capita level series is [`NE.CON.PRVT.PC.KD`](https://data.worldbank.org/indicator/NE.CON.PRVT.PC.KD), locally pinned in a 2026-05-05 fetch manifest. Replacing the registered source after the old result is a substantive measurement correction. |
| 1970–2020 panel with non-overlapping 10-year windows | The [2026-07-23 WITS mirror manifest](../../data/manifests/fetch_run_2026-07-23T151550Z.yaml) pins the tariff vintage, but its non-null cells among the registered countries begin in **1988**; WGI `RL.EST` begins in **1996**. A key/non-null coverage scan found no local tariff observations for 1970–1987. Choosing shorter windows or a later analysis period would change the frozen sample. |
| Duration and two-outcome decision | No locked derivation defines how missing tariff years enter the cumulative count, nor how annual observations are collapsed into each 10-year window. The original run supplies neither separate outcome estimates nor the high-income/catch-up split. |
| Registered controls and exclusions | The declared WDI terms-of-trade vintage is absent locally; the old generic run did not implement its war, extreme-openness, or commodity-boom exclusions. Dropping or substituting these after the result would be new analysis choices. |
